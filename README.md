what I still want to add. Less "how the code works," more "where things stand."

still my favorite way to explain myself: more questions than answers, and I mean that

## Why it looks the way it looks

Four color themes a visitor can pick — Monochrome, Ember, Hot Pink, Hacker Green —
because I didn't want to commit to one mood for the whole site. Dark, a little
atmospheric, drifting color in the background, small stars. My own fonts throughout
(Antikor Mono, Druk Wide Super, a little Katherine Script). It's supposed to feel like
mine, not like a template.
